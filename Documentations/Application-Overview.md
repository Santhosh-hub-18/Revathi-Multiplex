# Revathi Multiplex – Movie Ticket Booking Management

## 1. Project Overview

Revathi Multiplex is a Pega-based movie ticket booking management application designed to automate and manage the movie ticket booking lifecycle.

The application allows customers to submit movie ticket booking requests and enables the booking team to process the requests through a structured case lifecycle.

The application is developed using Pega App Studio and uses Pega Case Management concepts such as stages, processes, personas, data objects, business rules, work queues, SLAs, and notifications.

## 3. Purpose

The purpose of the application is to provide a structured and automated process for handling movie ticket booking requests.

The application helps manage:

- Customer booking requests
- Movie and show information
- Show availability
- Seat availability
- Ticket cost calculation
- Customer confirmation
- Seat allocation
- Ticket generation
- Booking status
- Work queue routing
- SLA management
- Booking notifications

## 4. Key Features

- Case-based movie ticket booking
- Customer information management
- Movie and show management
- Availability verification
- Seat availability validation
- Automatic ticket cost calculation
- Customer confirmation
- Seat allocation
- Ticket ID generation
- Work queue routing
- SLA monitoring
- Booking confirmation notification

## 5. Expected Outcome

The application provides an organized movie ticket booking process that reduces manual activities and improves the visibility and consistency of booking requests.
