# Case Lifecycle

## 1. Primary Case Type

The primary case type in the application is:

**Movie Ticket Request**

## 2. Case Lifecycle Stages

The movie ticket booking process is divided into the following stages:

1. Booking Request
2. Availability
3. Approval
4. Booking Execution

## 3. Overall Workflow

```text
Customer submits booking request
              ↓
Validate booking information
              ↓
Check show availability
              ↓
Check seat availability
              ↓
Calculate total cost
              ↓
Review booking details
              ↓
Customer confirms booking
              ↓
Route booking request
              ↓
Process ticket booking
              ↓
Allocate seats
              ↓
Generate Ticket ID
              ↓
Confirm booking
              ↓
Resolve case
              ↓
Send confirmation notification
