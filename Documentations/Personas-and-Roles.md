# Personas and Roles

## 1. Overview

The Revathi Multiplex application uses personas and roles to define the responsibilities of users involved in the movie ticket booking process.

## 2. Customer

The Customer initiates and confirms a movie ticket booking request.

### Responsibilities

- Submit a movie ticket booking request
- Provide customer information
- Select a movie and show
- Specify the number of tickets
- Review booking details
- Confirm the booking
- Cancel the booking if required

## 3. Booking Agent

The Booking Agent processes and manages customer booking requests.

### Responsibilities

- Review booking requests
- Verify movie and show availability
- Check seat availability
- Verify booking information
- Process ticket bookings
- Allocate seats
- Complete booking processing

## 4. System

The system performs automated activities during the case lifecycle.

### Responsibilities

- Validate booking information
- Calculate ticket cost
- Apply business rules
- Route cases
- Monitor SLA
- Generate Ticket ID
- Send booking notifications
- Update booking status

## 5. Role Summary

| Persona | Main Responsibility |
|---|---|
| Customer | Submit and confirm movie booking |
| Booking Agent | Verify and process bookings |
| System | Automate validation, calculation, routing and notifications |
